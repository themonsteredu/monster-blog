# 몬스터 블로그 — 확장을 품은 설치형 프로그램 (v3.1)

크롬 확장프로그램을 **설치파일 하나로** 배포하는 방식입니다.
고객은 개발자 모드도, 폴더 로드도 몰라도 됩니다.

## 어떻게 동작하나

프로그램은 글을 대신 쓰지 않습니다. **확장이 이미 심어진 크롬을 띄워주기만** 합니다.

```
설치파일 실행 → 바탕화면 아이콘 클릭 → [🚀 글쓰기 시작]
   → 확장이 들어있는 크롬이 열림 → 확장 아이콘 눌러 글쓰기
```

글을 쓰는 부분은 검증된 확장 코드(`../extension`)를 **그대로** 씁니다.
크롬드라이버·셀레늄·자동 로그인이 없으므로 고장날 곳이 거의 없습니다.

| | 확장 직접 설치 | 이 방식 (v3.0) | 셀레늄 자동화 (구버전 `desktop/`) |
|---|---|---|---|
| 고객 설치 | 개발자 모드 + 폴더 로드 | **설치파일 더블클릭** | 설치파일 더블클릭 |
| 로그인 | 평소 크롬 그대로 | 전용 크롬에 처음 한 번 | 프로그램이 자동 시도(네이버가 차단) |
| 고장 위험 | 낮음 | **낮음** | 높음(프로필·드라이버·화면 구조) |

## 개발 컴퓨터에서 실행 (포장 전 확인)

```bash
pip install customtkinter
python launcher/launcher.py
```

## 설치파일 만들기 (한 번만)

1. `launcher\build_exe.bat` 더블클릭 → `launcher\dist\MonsterBlog\MonsterBlog.exe` 생성
2. [Inno Setup](https://jrsoftware.org/isinfo.php)(무료) 설치 → `launcher\installer.iss` 열고 **Compile**
3. `launcher\Output\MonsterBlogSetup.exe` → **고객에게 이 파일 하나만** 보내면 끝

## 크롬 보안정책 관련 (중요)

2025년부터 크롬은 명령줄로 확장을 자동 적재하는 `--load-extension` 을 기본 차단합니다.
런처는 이 차단을 끄는 옵션(`--disable-features=DisableLoadExtensionCommandLineSwitch`)을
함께 넘기지만, 크롬 버전에 따라 그래도 막힐 수 있습니다.

그 경우 **처음 한 번만** 수동 등록하면 되고, 전용 프로필에 남으므로 이후에는 계속 유지됩니다.

1. 런처의 **[📂 확장 폴더 열기]** 로 경로 확인 (`%USERPROFILE%\.monster_blog\extension`)
2. 열린 크롬에서 `chrome://extensions` → 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 위 폴더 선택

확장 폴더는 exe 안이 아니라 위 고정 경로로 복사되므로, 프로그램을 업데이트해도
수동 등록이 풀리지 않습니다.

## 고객 사용 순서

1. `MonsterBlogSetup.exe` 실행해 설치 → 바탕화면 아이콘 더블클릭
2. **[🚀 글쓰기 시작]** 클릭 → 크롬이 열림
3. **처음 한 번만:**
   - 네이버에 로그인 (다음부터는 유지됩니다)
   - 주소창 오른쪽 퍼즐(🧩) → '몬스터 블로그' 옆 압정(📌)으로 고정
4. 글쓰기 화면에서 확장 아이콘 클릭 → 주제 입력 → 글 생성 → 네이버에 입력 → 발행

## 참고

- 확장 전용 크롬 프로필은 `%USERPROFILE%\.monster_blog\chrome` 에 저장됩니다.
  평소 쓰는 크롬과 분리되어 서로 방해하지 않습니다.
- Claude API 키·학원 정보는 확장 팝업의 **⚙️ 설정**에서 넣습니다(그 브라우저에만 저장).
- 확장을 고치면(`../extension`) 다시 빌드만 하면 반영됩니다.
