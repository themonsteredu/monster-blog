# 더몬스터학원 블로그 자동화 — 설치형 데스크톱 프로그램 (확장 없는 버전)

시중에 파는 블로그 프로그램들처럼 **설치파일 하나로 설치**하고,
**카톡처럼 프로그램 안에서 네이버 아이디로 로그인**한 다음,
글 생성 → 자동 입력 → **임시저장 / 바로 발행 / 예약 발행**까지 하는 버전입니다.

크롬 확장프로그램 버전(`extension/`)과 알맹이는 같고, 겉모습(설치·사용 방식)만 다릅니다.

## 확장 버전과 무엇이 다른가

| | 확장프로그램 (`extension/`) | 설치형 (`desktop/`) |
|---|---|---|
| 설치 | 크롬 개발자 모드로 폴더 로드 | **설치파일 더블클릭** |
| 로그인 | 평소 쓰는 크롬에 이미 로그인돼 있음 | **프로그램 안에서 아이디/비번 입력** (첫 로그인만 캡차 가능) |
| 사용 | 네이버 글쓰기 화면 열고 팝업 조작 | 프로그램 창 하나에서 전부 |
| 발행 | 임시저장/바로/예약 | 임시저장/바로/예약 (동일) |
| 약점 | "디버깅 시작" 노란 띠, 개발자 모드 낯섦 | 프로그램이 크롬 창을 하나 새로 띄움 |

두 버전 모두 네이버가 글쓰기 화면을 바꾸면 선택자 수정이 필요한 건 같습니다.
예약 발행은 네이버 서버에 등록되므로 **예약 후 컴퓨터를 꺼도** 그 시간에 발행됩니다.

## 개발 컴퓨터에서 실행 (포장 전 테스트)

```bash
pip install selenium anthropic pillow
python desktop/main.py
```

크롬이 설치되어 있어야 합니다 (드라이버는 셀레늄이 자동으로 받아줌).

## 설치파일 만들기 (사장님/개발 컴퓨터에서 한 번)

1. `desktop\build_exe.bat` 더블클릭 → `desktop\dist\MonsterBlog\MonsterBlog.exe` 생성
2. [Inno Setup](https://jrsoftware.org/isinfo.php) (무료) 설치 → `desktop\installer.iss` 열고 **Compile**
3. `desktop\Output\MonsterBlogSetup.exe` 하나가 나옴 → **고객에게는 이 파일만 보내면 됨**

맥 배포가 필요하면 pyinstaller 를 맥에서 한 번 더 돌리면 됩니다 (`.app` 생성).

## 고객 사용 순서

1. `MonsterBlogSetup.exe` 실행해 설치 → 바탕화면 아이콘 더블클릭
2. ⚙️ 설정 → **Claude API 키** + **우리 학원 정보** 입력 → 저장
3. 네이버 아이디/비밀번호 넣고 **로그인** (처음 한 번은 크롬 창에서 캡차를 풀어야 할 수 있음 — 그 뒤로는 자동)
4. 주제·키워드 입력, 사진 있으면 선택 → **✨ 글 생성**
5. 결과 확인·수정 → 발행 방식 선택(임시저장/바로/예약) → **🚀 네이버에 올리기**
6. 프로그램이 띄운 크롬 창에서 실시간으로 써지는 걸 볼 수 있음 (창은 건드리지 말기)

## 정직한 한계

- 네이버가 화면 구조를 바꾸면 `robot.py` 의 선택자(JS)를 고쳐야 합니다 (확장과 동일한 숙제).
- 첫 로그인은 캡차/새 기기 확인 때문에 사람이 크롬 창에서 직접 마무리해야 할 수 있습니다.
  로그인 세션은 `~/.monster_blog/chrome_profile` 에 저장되어 다음부터는 자동입니다.
- 예약 시간 입력칸을 프로그램이 못 다루는 화면이면, **엉뚱한 시간에 발행되지 않도록** 창을
  열어둔 채 멈추고 "시간만 직접 맞추고 발행을 눌러주세요"라고 안내합니다.
- 아이디/비번/API 키는 이 컴퓨터의 `~/.monster_blog/settings.json` 에만 저장됩니다 (외부 전송 없음).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 프로그램 화면 (로그인/글 만들기/올리기/설정) — Tkinter |
| `generate.py` | 글 생성 (Claude) + 학원 정보로 전용 틀 자동 생성 |
| `robot.py` | 네이버 로봇 (로그인·자동 입력·인용구·사진·지도·발행/예약) — Selenium |
| `banner.py` | 하단 연락처 배너 + 인용구 카드 이미지 — Pillow |
| `build_exe.bat` | .exe 포장 (PyInstaller) |
| `installer.iss` | 설치파일 만들기 (Inno Setup) |
